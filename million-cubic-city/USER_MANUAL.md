# 新未来城 (Neo-City) 网站用户操作手册

## 1. 简介
本网站是一个展示2100年可持续大都市"新未来城"的交互式平台。网站集成了3D城市模型、数据可视化展示以及用户互动功能。

## 2. 功能指南

### 2.1 语言切换
- **功能位置**: 导航栏右侧。
- **操作**: 点击 "中/EN" 按钮即可在中文和英文之间实时切换。
- **说明**: 切换语言不会刷新页面，所有内容即时更新。

### 2.2 3D 城市漫游
- **旋转**: 按住鼠标左键并拖动。
- **平移**: 按住鼠标右键并拖动。
- **缩放**: 滚动鼠标滚轮。
- **热点交互**: 点击城市中的红色热点标记，可查看特定地标（如中央枢纽、生态区）的详细信息。
- **昼夜切换**: 点击导航栏上的 ☀️/🌙 图标，可切换城市的昼夜景观。

### 2.3 内容浏览
网站包含以下板块，可通过导航栏快速跳转或向下滚动浏览：
- **城市故事**: 时间轴展示城市发展历程。
- **能源系统**: 实时显示能源产出与分配数据。
- **科技发展**: 点击不同科技卡片（如量子计算、全息界面）查看详情。
- **环境规划**: 查看绿化覆盖与空气质量指标。
- **人口统计**: 了解城市的人口构成与幸福指数。

### 2.4 资料上传与互动
位于页面底部的"世界资料上传"模块，现支持**分模块管理**：
- **模块选择**: 
    - 点击顶部的模块按钮（如"城市故事"、"能源系统"等）切换当前的上传工作区。
    - 每个模块拥有独立的上传队列和评论区。
- **上传文件**: 
    - 确认当前选中的模块是否正确。
    - 将文件拖入虚线框区域，或点击虚线框选择文件。
    - 支持格式: PDF, PNG, JPG, MP4 (最大 50MB)。
    - 上传后可查看图片/视频预览。
    - 点击 "提交资料" 完成上传（上传记录将保存在对应模块下）。
- **评论互动**:
    - 评论区内容会随选择的模块自动切换。
    - 在右侧评论区查看特定模块的讨论。
    - 在输入框输入内容并点击发送图标即可发布新评论。

## 3. 常见问题
- **Q: 3D模型加载缓慢怎么办？**
  - A: 请确保您的网络连接正常，且浏览器支持 WebGL (推荐使用 Chrome, Firefox, Edge)。
- **Q: 移动端可以访问吗？**
  - A: 可以。网站采用响应式设计，支持手机和平板访问。在移动端，使用单指拖动旋转，双指拖动平移。
